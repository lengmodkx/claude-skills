# 消费统计助手

自动统计日记中的今日消费清单并填写统计数据。

## 快速开始

### 统计今日消费

从当前日记文件中提取消费清单并自动填写统计数据：

```bash
python -m consumption_statistics
```

指定日期：

```bash
python -m consumption_statistics --date 2026-01-01
```

指定日记文件路径：

```bash
python -m consumption_statistics --file "日记/2026年/一月/第一周/2026-01-01.md"
```

## 日记格式

### 今日消费清单格式

日记中的消费清单必须是 Markdown 表格格式：

```markdown
#### 📊 今日消费清单
|  时间   |  类别   | 金额（元） | 备注     |
| :---: | :---: | :---: | :----- |
| 10:05 | 🍜 餐饮 | 22.7  | 包子     |
| 14:14 | 🛒 购物 |  59   | 棍刀     |
```

### 今日统计格式

统计数据将按照以下格式填写：

```markdown
#### 📈 今日统计
- **消费笔数**：5 笔
- **总支出**：💰 **114.25** 元
- **最大支出**：59 元（购物-棍刀）
- **主要类别**：餐饮（4笔）
```

## 统计逻辑

1. **消费笔数**：表格中的行数
2. **总支出**：所有消费金额的总和
3. **最大支出**：单笔最高的消费，显示类别和备注
4. **主要类别**：消费次数最多的类别

## 工作流程

1. 读取日记文件
2. 查找"📊 今日消费清单"表格
3. 解析表格数据（时间、类别、金额、备注）
4. 计算统计数据
5. 查找或创建"📈 今日统计"部分
6. 更新统计结果

## 注意事项

- 消费清单表格必须包含：时间、类别、金额（元）、备注 四列
- 金额列必须是数字格式
- 如果今日统计部分已存在，将被覆盖
- 如果今日消费清单不存在，脚本将提示用户

## 使用场景

- 每日记录消费后，快速生成统计
- 查看今日消费概览
- 月底或年底消费汇总分析
