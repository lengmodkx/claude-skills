# Lemon Code Review

## 触发场景

当用户请求：
- 审查指定路径的代码
- 检查代码中的 bug 或潜在问题
- 优化代码质量和性能
- 结合参考文档进行规范性审查

## 工作流程

### 1. 收集信息

从用户请求中提取：
- **代码路径**: 需要审查的文件或目录
- **审查范围**: 整体审查、特定功能、还是特定类型的问题
- **参考内容**: 编码规范、设计文档、API 规范等
- **关注点**: 安全性、性能、可维护性、业务逻辑等

### 2. 代码审查

使用 Read 工具读取目标代码，按以下维度检查：

| 维度 | 检查内容 |
|------|----------|
| **业务逻辑** | 业务流程是否正确、边界条件处理、异常流程 |
| **安全性** | SQL 注入、XSS、权限校验、敏感数据、硬编码密钥 |
| **性能** | N+1 查询、大对象、空循环、缓存使用 |
| **规范** | 命名规范、注释、代码结构、异常处理 |
| **最佳实践** | 设计模式使用、资源关闭、事务管理 |

### 3. 对比参考

如果用户提供了参考内容：
- 对照参考规范检查代码合规性
- 检查 API 接口是否符合设计文档
- 验证数据结构是否符合预期

### 4. 输出报告

审查结果按以下格式输出：

```markdown
## 代码审查报告

### 基本信息
- 审查文件: xxx
- 审查时间: 2024-xx-xx
- 审查人员: Claude

### 问题列表

| 严重程度 | 问题描述 | 位置 | 建议修复 |
|---------|---------|------|---------|
| 🔴 严重 | SQL 注入风险 | UserMapper.java:45 | 使用 #{} 而非 ${} |
| 🔴 严重 | 硬编码数据库密码 | application.yml:12 | 使用环境变量 |
| 🟡 警告 | 性能优化 | UserService.java:78 | 添加缓存注解 |

### 优化建议
...
```

### 5. 代码优化

根据审查结果，用户确认后执行优化：
- 使用 Edit 工具修改代码
- 保持最小改动原则
- 提供优化前后的对比

## 审查清单

### 通用检查
- [ ] 空指针检查
- [ ] 资源关闭（流、连接）
- [ ] 异常处理完整性
- [ ] 日志记录适当
- [ ] 命名清晰规范

### Java/Spring 检查
- [ ] 依赖注入正确使用
- [ ] 事务注解范围合理
- [ ] AOP 切点表达式正确
- [ ] MyBatis 参数绑定安全
- [ ] VO/DTO 转换完整

### 安全检查
- [ ] 权限校验完整性
- [ ] 敏感数据脱敏
- [ ] 输入参数校验
- [ ] SQL 注入防护
- [ ] 接口访问控制

### 敏感信息检测（新增）
- [ ] 硬编码密码检查（password, passwd, pwd）
- [ ] 硬编码密钥检查（secret, api_key, access_key, private_key）
- [ ] Token 硬编码检查（token, jwt, bearer, auth_token）
- [ ] 数据库连接字符串检查（jdbc:, mongodb:, redis:）
- [ ] 外部 API 端点检查（包含 key 或 secret 的 URL）
- [ ] 配置文件敏感信息（application*.yml, application*.properties）
- [ ] AWS/Azure/GCP 凭证检查（AWS_ACCESS, AZURE_KEY, GOOGLE_CREDENTIALS）
- [ ] 第三方服务凭证（stripe, paypal, alipay, wechat）
- [ ] 测试/示例凭证（test-key, example-secret, dummy_token）

**敏感信息检测优先级：🔴 严重（必须修复）**

检测到敏感信息时，必须：
1. 标记为 🔴 严重问题
2. 明确指出敏感信息的位置和类型
3. 提供安全替代方案（环境变量、配置中心、密钥管理服务）
4. 警告用户该信息可能已泄露到版本控制系统

## 输出要求

1. **问题分级**:
   - 🔴 严重（必须修复）
   - 🟡 警告（建议修复）
   - 🟢 提示（可优化）

2. **每问题包含**:
   - 问题描述
   - 错误代码位置
   - 根本原因分析
   - 修复建议代码

3. **优化后代码**: 提供完整可运行的修复代码

4. **敏感信息处理**:
   - 发现敏感信息必须标记为 🔴 严重
   - 提供清晰的修复方案
   - 建议使用环境变量或密钥管理服务
   - 警告相关凭证需要更换
