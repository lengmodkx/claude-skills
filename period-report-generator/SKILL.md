# 周期统计报表生成器

根据日记文件自动生成周/月统计报表，支持使用 ascii-chart-to-svg 技能生成SVG图表。

## 快速开始

### 生成周报表（纯文本）

```bash
python -m period_report --type week --year 2025 --month 12 --week 52
```

### 生成周报表（含 AI 图表）

```bash
python -m period_report --type week --year 2026 --month 1 --week 3 --ai-charts
```

### 指定日记目录

```bash
python -m period_report --type week --year 2026 --month 1 --week 1 --base-dir "D:\lemonArticle\my-article"
```

## 新功能 🎉

### SVG 图表生成

使用 ascii-chart-to-svg 技能生成高质量的SVG数据图表：

1. **血糖监测趋势图**：柱状图显示空腹血糖和睡前血糖的变化
2. **每日消费趋势图**：柱状图显示每日消费金额
3. **任务完成率趋势图**：柱状图显示今日计划和工作/学习任务的完成率

所有图表使用 SVG 矢量格式生成，具有以下特点：
- 🎨 清晰专业的可视化效果
- 📊 准确的数据标注和网格线
- 🎯 适合报告演示的高质量输出
- 🖼️ SVG 格式，可缩放不失真
- ⚡ 快速生成，无需网络连接

### 使用 ascii-chart-to-svg 技能

图表生成依赖于 **ascii-chart-to-svg** 技能，该技能能够解析文本格式的图表数据并生成SVG矢量图。

**注意**：使用 SVG 图表功能需要：
1. 安装 ascii-chart-to-svg 技能
2. 无需额外配置或API密钥
3. 完全本地化处理，数据安全

## 报表内容

### 🩸 血糖监测分析

- **空腹血糖**: 平均值、最小值、最大值、达标率 (正常范围: 3.9-6.1 mmol/L)
- **餐后2h血糖**: 平均值、最小值、最大值、达标率 (正常范围: 4.4-7.8 mmol/L)
- **睡前血糖**: 平均值、最小值、最大值、达标率 (正常范围: 4.4~7.8 mmol/L)
- **AI 趋势图**: 可视化血糖变化趋势（使用 --ai-charts 时）

### 💰 消费趋势分析

- **总支出**: 统计周期内的总消费金额
- **日均消费**: 平均每日消费金额
- **消费笔数**: 总消费交易笔数
- **有消费天数**: 有消费记录的天数
- **单日最高**: 单日最高消费金额
- **主要消费类别**: 出现频率最高的消费类别
- **AI 柱状图**: 可视化每日消费趋势（使用 --ai-charts 时）

### 🎯 目标完成情况

- **今日计划完成率**: 计划任务完成百分比
- **工作/学习任务完成率**: 工作/学习任务完成百分比
- **AI 折线图**: 可视化任务完成率趋势（使用 --ai-charts 时）

## 工作流程

1. 扫描指定时间范围的日记文件
2. 提取血糖数据（空腹、餐后2h、睡前）
3. 提取消费数据（总支出、消费笔数、主要类别）
4. 提取任务完成情况（今日计划、工作/学习任务）
5. 计算统计指标和趋势分析
6. **（可选）使用 ascii-chart-to-svg 生成 SVG 图表**
7. 生成 Markdown 格式报表（包含图表引用）
8. 保存到对应的周/月目录

## 日记格式要求

### 血糖数据格式

```markdown
- 血糖监测（mmol/L）：
  - 🌅 空腹（≥8h未进食 3.9~6.1）：5.4
  - 🍚 餐后2h（从第一口进食算起 4.4~7.8）：7.2
  - 🌙 睡前（22:00前 4.4~7.8）：6.8
```

### 消费数据格式

需要日记中已包含"今日统计"部分：

```markdown
#### 📈 今日统计
- **消费笔数**：5 笔
- **总支出**：💰 **114.25** 元
- **最大支出**：59 元（购物-棍刀）
- **主要类别**：餐饮（4笔）
```

### 任务完成格式

```markdown
### 1. 今日计划
- [ ] 任务1
- [x] 任务2

### 2. 工作/学习
- [x] 任务1 ✅ 2025-12-26
- [ ] 任务2
```

## 参数说明

| 参数 | 说明 | 必需 | 默认值 |
| :--- | :--- | :---: | :--- |
| --type, -t | 报表类型 (week/month) | ✅ | - |
| --year, -y | 年份 | ❌ | 当前年 |
| --month, -m | 月份 | ❌ | 当前月 |
| --week, -w | 周数 (周报时必需) | 周* | - |
| --base-dir, -b | 日记基础目录 | ❌ | . |
| --output, -o | 输出文件路径 | ❌ | 自动生成 |
| --ai-charts | 使用 ascii-chart-to-svg 生成 SVG 图表 | ❌ | False |

## 使用场景

- **每周回顾**: 生成周报表，了解本周健康和消费情况
- **每月总结**: 生成月报表，回顾整月的各项指标
- **健康监控**: 追踪血糖变化趋势，及时调整生活方式
- **财务管理**: 分析消费趋势，优化支出结构
- **目标管理**: 查看任务完成率，提升自我管理效率
- **报告发布**: 使用 AI 图表生成高质量的可视化内容

## AI 图表说明

### 血糖趋势图（多折线图）

- 蓝色线条：空腹血糖
- 红色线条：睡前血糖
- Y轴单位：mmol/L
- 参考线：正常范围（空腹 3.9-6.1，睡前 4.4-7.8）

### 消费趋势图（柱状图）

- 绿色柱子：每日消费金额
- Y轴单位：元
- 柱子高度：相对比例

### 任务完成率图（多折线图）

- 紫色线条：今日计划完成率
- 濫色线条：工作/学习任务完成率
- Y轴单位：百分比（%）

## 注意事项

- 日记文件必须按照标准格式命名: YYYY-MM-DD.md
- 血糖数据需要从"生活/健康"部分提取
- 消费数据需要日记中已有"今日统计"部分（建议配合 consumption-statistics 技能使用）
- 任务完成情况根据 checkbox 和 ✅ 标记统计
- 报表会自动保存在对应的周/月目录下
- **使用 --ai-charts 需要：**
  - ascii-chart-to-svg 技能已安装
  - 无需额外配置或API密钥
  - 完全本地化处理，数据安全
- **SVG 图表生成时间**：每个图表约需 1-3 秒
- **SVG 图表特点**：
  - 精确的数据可视化
  - 清晰的网格线和标签
  - 可缩放不失真的矢量格式
  - 适合文档嵌入和打印

## 故障排查

### SVG 图表未生成

1. **检查 ascii-chart-to-svg 技能**：
   ```bash
   ls "C:/Users/Administrator/.claude/skills/ascii-chart-to-svg/scripts/chart_to_svg.py"
   ```

2. **检查脚本路径**：确保 chart_to_svg.py 文件存在于正确的位置

3. **查看错误信息**：脚本会输出详细的错误信息

### 技能依赖安装

如果缺少 ascii-chart-to-svg 技能，请通过技能管理器安装。该技能需要：
- Python 3.6+
- 无需额外依赖

### 图表样式问题

SVG 图表使用统一的样式模板，具有以下特点：
- 清晰专业的数据可视化
- 绿色柱状图显示数据
- 灰色网格线和坐标轴
- 可通过修改脚本自定义样式

如需自定义图表样式，可以编辑 chart_to_svg.py 脚本中的 CSS 样式部分。
