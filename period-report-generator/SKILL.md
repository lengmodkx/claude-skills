# 周期统计报表生成器

根据日记文件自动生成周/月统计报表，支持使用 ascii-chart-to-svg 技能生成SVG图表。

## 快速开始

### 生成周报表（纯文本）

```bash
python -m period_report --type week --year 2025 --month 12 --week 52
```

### 生成周报表（含 AI 图表）

```bash
python -m period_report --type week --year 2026 --month 1 --week 3 --ai-charts
```

### 指定日记目录

```bash
python -m period_report --type week --year 2026 --month 1 --week 1 --base-dir "D:\lemonArticle\my-article"
```

## 新功能 🎉

### OKR统计支持

从v2.0开始，支持新的"日OKR管理"日记格式，提供以下统计维度：

- **任务分类统计**: 今日待办、临时任务、关键结果(KR)
- **状态维度**: 已完成、进行中、已取消
- **优先级维度**: P0(最高)、P1(高)、P2(中)
- **关联月OKR**: 按关联的月OKR分组统计

#### 日OKR管理格式

日记中需要包含以下格式的OKR内容：

```markdown
### 1. 日OKR管理
#### 🎯 Objective：今日目标描述

##### 关键结果（Key Results）
| 序号  | 关键任务 | 关联月OKR | 优先级 | 状态  |
| :-: | :--- | :--- | :-: | :-: |
| KR1 | 任务描述 | [[2026-03月OKR|月OKR]] | P2 | 已完成 |
| KR2 | 任务描述 | [[2026-03月OKR|月OKR]] | P1 | 进行中 |

##### 今日待办事项
- [x] 已完成任务
- [ ] 未完成任务

#### 临时任务
- [x] 已完成临时任务
```

#### 状态值说明

| 状态值 | 说明 | 统计方式 |
|:---|:---|:---|
| 已完成 | 任务已达成 | 计入完成数 |
| 进行中 | 任务正在推进 | 不计入完成，单独统计 |
| 已取消 | 任务已放弃 | 不计入完成，单独统计 |

### 报表文件命名规范

- **周报**：`第{X}周统计报表.md`
- **月报**：`{YYYY}年{MM}月统计报表.md`

### 跨月周统计

支持跨越月份的周统计（如3月30日-4月5日），会自动合并多个周目录的数据。

## 报表内容

### 🩸 血糖监测分析

- **空腹血糖**: 平均值、最小值、最大值、达标率 (正常范围: 3.9-6.1 mmol/L)
- **餐后2h血糖**: 平均值、最小值、最大值、达标率 (正常范围: 4.4-7.8 mmol/L)
- **睡前血糖**: 平均值、最小值、最大值、达标率 (正常范围: 4.4~7.8 mmol/L)
- **AI 趋势图**: 可视化血糖变化趋势（使用 --ai-charts 时）

### 💰 消费趋势分析

- **总支出**: 统计周期内的总消费金额
- **日均消费**: 平均每日消费金额
- **消费笔数**: 总消费交易笔数
- **有消费天数**: 有消费记录的天数
- **单日最高**: 单日最高消费金额
- **主要消费类别**: 出现频率最高的消费类别
- **AI 折线图**: 可视化每日消费趋势（使用 --ai-charts 时）

### 🎯 OKR目标完成情况

- **任务分类统计**: 今日待办、临时任务、关键结果(KR)的数量和完成率
- **状态维度统计**: 已完成、进行中、已取消的任务分布
- **优先级统计**: P0(最高)、P1(高)、P2(中)优先级任务的完成情况
- **月OKR关联统计**: 按关联的月OKR分组统计任务完成情况
- **AI 折线图**: 可视化任务完成率趋势（使用 --ai-charts 时）

## 工作流程

1. 扫描指定时间范围的日记文件
2. 提取血糖数据（空腹、餐后2h、睡前）
3. 提取消费数据（总支出、消费笔数、主要类别）
4. 提取OKR目标完成情况（今日待办、临时任务、关键结果）
5. 计算统计指标和趋势分析
6. **（可选）使用 ascii-chart-to-svg 生成 SVG 图表**
7. 生成 Markdown 格式报表（包含图表引用）
8. 保存到对应的周/月目录

## 日记格式要求

### 血糖数据格式

```markdown
- 血糖监测（mmol/L）：
  - 🌅 空腹（≥8h未进食 3.9~6.1）：5.4
  - 🍚 餐后2h（从第一口进食算起 4.4~7.8）：7.2
  - 🌙 睡前（22:00前 4.4~7.8）：6.8
```

### 消费数据格式

需要日记中已包含"今日统计"部分：

```markdown
#### 📈 今日统计
- **消费笔数**：5 笔
- **总支出**：💰 **114.25** 元
- **最大支出**：59 元（购物-棍刀）
- **主要类别**：餐饮（4笔）
```

### 任务完成格式（旧版）

```markdown
### 1. 今日计划
- [ ] 任务1
- [x] 任务2

### 2. 工作/学习
- [x] 任务1 ✅ 2025-12-26
- [ ] 任务2
```

### OKR数据格式（推荐v2.0）

```markdown
### 1. 日OKR管理
#### 🎯 Objective：今日目标描述

##### 关键结果（Key Results）
| 序号  | 关键任务 | 关联月OKR | 优先级 | 状态  |
| :-: | :--- | :--- | :-: | :-: |
| KR1 | 任务描述 | [[2026-03月OKR|月OKR]] | P2 | 已完成 |
| KR2 | 任务描述 | [[2026-03月OKR|月OKR]] | P1 | 进行中 |

##### 今日待办事项
- [x] 已完成任务
- [ ] 未完成任务

#### 临时任务
- [x] 已完成临时任务
```

## 参数说明

| 参数 | 说明 | 必需 | 默认值 |
| :--- | :--- | :---: | :--- |
| --type, -t | 报表类型 (week/month) | ✅ | - |
| --year, -y | 年份 | ❌ | 当前年 |
| --month, -m | 月份 | ❌ | 当前月 |
| --week, -w | 周数 (周报时必需) | 周* | - |
| --base-dir, -b | 日记基础目录 | ❌ | . |
| --output, -o | 输出文件路径 | ❌ | 自动生成 |
| --ai-charts | 使用 ascii-chart-to-svg 生成 SVG 图表 | ❌ | False |

## 使用场景

- **每周回顾**: 生成周报表，了解本周健康、消费和OKR完成情况
- **每月总结**: 生成月报表，回顾整月的各项指标
- **健康监控**: 追踪血糖变化趋势，及时调整生活方式
- **财务管理**: 分析消费趋势，优化支出结构
- **OKR管理**: 查看OKR目标完成情况，追踪关键结果达成进度
- **报告发布**: 使用 AI 图表生成高质量的可视化内容

## AI 图表说明

### 血糖趋势图（多折线图）

- 蓝色线条：空腹血糖
- 红色线条：睡前血糖
- Y轴单位：mmol/L
- 参考线：正常范围（空腹 3.9-6.1，睡前 4.4-7.8）

### 消费趋势图（折线图）

- 绿色线条：每日消费金额
- Y轴单位：元
- 数据点：显示具体数值

### 任务完成率图（多折线图）

- 紫色线条：今日计划完成率
- 濫色线条：工作/学习任务完成率
- Y轴单位：百分比（%）

## 注意事项

### 数据格式
- 日记文件必须按照标准格式命名: YYYY-MM-DD.md
- 血糖数据需要从"生活/健康"部分提取
- 消费数据需要日记中已有"今日统计"部分（建议配合 consumption-statistics 技能使用）
- OKR数据从"日OKR管理"部分提取，支持表格和列表格式
- 任务完成情况根据 checkbox 和 ✅ 标记统计

### 报表输出
- 报表会自动保存在对应的周/月目录下
- **周报文件名**：`第{X}周统计报表.md`
- **月报文件名**：`{YYYY}年{MM}月统计报表.md`
- **相关链接**：自动添加上周、下周、月视图的链接，格式为 `[[第X周统计报表]]`

### Markdown表格兼容性
生成的表格使用标准Markdown格式，确保在Obsidian中正确显示：
- 表格前有空白行
- 使用标准分隔符格式 `|------|`
- 避免使用对齐标记（如 `:---:`），提高兼容性

### 跨月周统计
支持跨越月份的周统计（如3月30日-4月5日），会自动：
1. 查找多个周目录的数据
2. 合并统计数据
3. 生成统一的报表

### SVG 图表特点
- **内置生成**：无需外部依赖，直接生成SVG折线图
- **包含图表**：血糖趋势图、消费趋势图、OKR完成率图
- **精确的数据可视化**：带数据点和数值标签
- **清晰的网格线和标签**
- **可缩放不失真的矢量格式**
- **适合文档嵌入和打印**

## 故障排查

### SVG 图表未生成

图表是内置生成的，如果未生成请检查：
1. 日记数据是否完整（至少需要有血糖或消费数据）
2. 日期格式是否正确（YYYY-MM-DD）
3. 查看脚本输出的错误信息

### 报表数据不完整

1. **跨月周统计**：如果周跨越月份（如3月30日-4月5日），确保两个月份的日记文件都存在
2. **文件编码**：确保日记文件使用UTF-8编码
3. **数据格式**：检查日记中的血糖、消费、OKR数据格式是否符合要求

### 图表样式问题

SVG 图表使用内置样式，如需自定义：
- 编辑 `generate_line_chart_svg` 函数中的 CSS 样式部分
- 修改颜色、字体、尺寸等参数
