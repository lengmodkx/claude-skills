# 周期统计报表生成器

根据日记文件自动生成周/月统计报表。

## 快速开始

### 生成周报表

```bash
python -m period_report --type week --year 2025 --month 12 --week 52
```

### 生成月报表

```bash
python -m period_report --type month --year 2025 --month 12
```

### 指定日记目录

```bash
python -m period_report --type week --year 2026 --month 1 --week 1 --base-dir "D:\lemonArticle\my-article"
```

## 报表内容

### 🩸 血糖监测分析

- **空腹血糖**: 平均值、最小值、最大值、达标率 (正常范围: 3.9-6.1 mmol/L)
- **餐后2h血糖**: 平均值、最小值、最大值、达标率 (正常范围: 4.4-7.8 mmol/L)
- **睡前血糖**: 平均值、最小值、最大值、达标率 (正常范围: 4.4-7.8 mmol/L)

### 💰 消费趋势分析

- **总支出**: 统计周期内的总消费金额
- **日均消费**: 平均每日消费金额
- **消费笔数**: 总消费交易笔数
- **有消费天数**: 有消费记录的天数
- **单日最高**: 单日最高消费金额
- **主要消费类别**: 出现频率最高的消费类别

### 🎯 目标完成情况

- **今日计划完成率**: 计划任务完成百分比
- **工作/学习任务完成率**: 工作/学习任务完成百分比

## 工作流程

1. 扫描指定时间范围的日记文件
2. 提取血糖数据（空腹、餐后2h、睡前）
3. 提取消费数据（总支出、消费笔数、主要类别）
4. 提取任务完成情况（今日计划、工作/学习任务）
5. 计算统计指标和趋势分析
6. 生成 Markdown 格式报表
7. 保存到对应的周/月目录

## 日记格式要求

### 血糖数据格式

```markdown
- 血糖监测（mmol/L）：
  - 🌅 空腹（≥8h未进食 3.9~6.1）：5.4
  - 🍚 餐后2h（从第一口进食算起 4.4~7.8）：7.2
  - 🌙 睡前（22:00前 4.4~7.8）：6.8
```

### 消费数据格式

需要日记中已包含"今日统计"部分：

```markdown
#### 📈 今日统计
- **消费笔数**：5 笔
- **总支出**：💰 **114.25** 元
- **最大支出**：59 元（购物-棍刀）
- **主要类别**：餐饮（4笔）
```

### 任务完成格式

```markdown
### 1. 今日计划
- [ ] 任务1
- [x] 任务2

### 2. 工作/学习
- [x] 任务1 ✅ 2025-12-26
- [ ] 任务2
```

## 报表示例

### 周报表

保存在: `日记/YYYY年/MM月/第N周/第N周统计报表.md`

内容包括：
- 概览（统计周期、记录天数）
- 血糖监测分析（含趋势图表）
- 消费趋势分析
- 目标完成情况
- 建议与总结

### 月报表

保存在: `日记/YYYY年/MM月/YYYY年MM月统计报表.md`

内容包括：
- 概览（统计周期、记录天数）
- 血糖监测分析
- 消费趋势分析
- 目标完成情况
- 建议与总结

## 参数说明

| 参数 | 说明 | 必需 | 默认值 |
| :--- | :--- | :---: | :--- |
| --type, -t | 报表类型 (week/month) | ✅ | - |
| --year, -y | 年份 | ❌ | 当前年 |
| --month, -m | 月份 | ❌ | 当前月 |
| --week, -w | 周数 (周报时必需) | 周* | - |
| --base-dir, -b | 日记基础目录 | ❌ | . |
| --output, -o | 输出文件路径 | ❌ | 自动生成 |

## 使用场景

- **每周回顾**: 生成周报表，了解本周健康和消费情况
- **每月总结**: 生成月报表，回顾整月的各项指标
- **健康监控**: 追踪血糖变化趋势，及时调整生活方式
- **财务管理**: 分析消费趋势，优化支出结构
- **目标管理**: 查看任务完成率，提升自我管理效率

## 注意事项

- 日记文件必须按照标准格式命名: YYYY-MM-DD.md
- 血糖数据需要从"生活/健康"部分提取
- 消费数据需要日记中已有"今日统计"部分（建议配合 consumption-statistics 技能使用）
- 任务完成情况根据 checkbox 和 ✅ 标记统计
- 报表会自动保存在对应的周/月目录下
