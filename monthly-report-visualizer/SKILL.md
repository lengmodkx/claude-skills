# 月度报表可视化生成器

根据日记文件自动生成带有高质量可视化图表的月统计报表。

## 快速开始

### 生成完整月报（包含图表）

```bash
python scripts/generate_charts.py --year 2026 --month 3 --base-dir "D:\myfile\myArticle\my-article"
```

### 仅生成图表（不插入月报）

```bash
python scripts/generate_charts.py --year 2026 --month 3 --base-dir "D:\myfile\myArticle\my-article" --charts-only
```

### 指定输出目录

```bash
python scripts/generate_charts.py --year 2026 --month 3 --output "minimax-output"
```

## 功能特性

### 自动统计维度

1. **睡眠质量分析**
   - 睡眠差/一般/好的天数分布
   - 良好睡眠率计算

2. **血糖监测分析**
   - 空腹血糖（平均值、最小值、最大值、达标率）
   - 餐后2h血糖（平均值、最小值、最大值、达标率）
   - 睡前血糖（平均值、最小值、最大值、达标率）
   - 正常范围参考线标注

3. **消费趋势分析**
   - 总支出、日均消费、消费笔数
   - 按类别分布（餐饮、购物、交通、娱乐、其他）
   - 单日最高消费

4. **OKR目标完成情况**
   - 任务类型统计（今日待办、临时任务、关键结果KR）
   - 按优先级统计（P0、P1、P2完成率）
   - 整体完成率计算

| 图表 | 文件名 | 类型 |
|:---|:---|:---|
| 睡眠质量分布 | `01_睡眠质量分布.png` | 环形图 |
| 血糖监测分析 | `02_血糖监测分析.png` | 分组柱状图+参考线 |
| 消费趋势分析 | `03_消费趋势分析.png` | 环形图+统计卡片 |

| 综合数据看板 | `2026年X月数据看板.png` | 综合仪表板 |

## 工作流程

1. **扫描日记文件**
   - 读取指定年月的日记文件（格式：`YYYY-MM-DD.md`）
   - 从日记中提取睡眠、血糖、消费、OKR数据

2. **统计数据**
   - 计算各项指标（平均值、达标率、完成率等）
   - 汇总各类别的分布情况

3. **生成图表**
   - 使用 ECharts 生成 HTML 图表文件
   - 启动本地 HTTP 服务器
   - 使用 Playwright 截图生成 PNG 图片

4. **插入月报**
   - 读取现有的月报 Markdown 文件
   - 在对应章节插入图表图片引用
   - 保存更新后的月报

## 图表样式

所有图表采用统一的设计风格：

- **深色主题**：渐变背景 + 玻璃态效果
- **专业配色**：
  - 红色：`#e74c3c`（警告、高优先级）
  - 橙色：`#f39c12`（一般、中优先级）
  - 绿色：`#27ae60`（成功、已完成）
  - 蓝色：`#3498db`（信息、平均值）
- **清晰标注**：数据标签、图例、提示框
- **高分辨率**：适合文档嵌入和展示

## 日记格式要求

### 睡眠质量数据

```markdown
#### 😴 睡眠质量
- 睡眠质量：差|一般|好
```

### 血糖数据

```markdown
#### 🩸 血糖监测（mmol/L）：
- 🌅 空腹（≥8h未进食 3.9~6.1）：5.4
- 🍚 餐后2h（从第一口进食算起 4.4~7.8）：7.2
- 🌙 睡前（22:00前 4.4~7.8）：6.8
```

### 消费数据

```markdown
#### 📈 今日统计
- **消费笔数**：5 笔
- **总支出**：💰 **114.25** 元
- **最大支出**：59 元（购物-棍刀）
- **主要类别**：餐饮（4笔）
```

### OKR数据

```markdown
### 1. 日OKR管理
#### 🎯 Objective：今日目标描述

##### 关键结果（Key Results）
| 序号 | 关键任务 | 关联月OKR | 优先级 | 状态 |
| :-: | :--- | :--- | :-: | :-: |
| KR1 | 任务描述 | [[2026-03月OKR|月OKR]] | P2 | 已完成 |

##### 今日待办事项
- [x] 已完成任务
- [ ] 未完成任务

#### 临时任务
- [x] 已完成临时任务
```

## 参数说明

| 参数 | 说明 | 必需 | 默认值 |
|:---|:---|:---:|:---|
| --year, -y | 年份 | ❌ | 当前年 |
| --month, -m | 月份 | ❌ | 当前月 |
| --base-dir, -b | 日记基础目录 | ❌ | 当前目录 |
| --output, -o | 图片输出目录 | ❌ | `minimax-output` |
| --charts-only | 仅生成图表，不插入月报 | ❌ | False |

## 输出文件

### 图表图片

所有图片保存在指定的输出目录（默认 `minimax-output/`）：

```
minimax-output/
├── 01_睡眠质量分布.png
├── 02_血糖监测分析.png
├── 03_消费趋势分析.png
├── 04_OKR完成情况.png
└── 2026年3月数据看板.png
```

月报文件保存在：`日记/2026年/3月/2026年3月统计报表.md`

```markdown
## 😴 睡眠质量分析

![睡眠质量分布](../../../minimax-output/01_睡眠质量分布.png)

- **睡眠质量分布**: 差 21 天 | 一般 9 天 | 好 0 天
```

## 依赖要求

### Python 依赖

```bash
pip install playwright
playwright install chromium
```

### 系统要求

- Python 3.8+
- 支持运行 Playwright 的浏览器

## 故障排查

### Playwright 未安装

```bash
pip install playwright
playwright install chromium
```

### 图表生成失败

1. 检查日记文件是否存在且格式正确
2. 确保端口 8765 未被占用（或修改脚本中的端口）
3. 查看 Python 错误输出获取详细信息

### 图片插入失败

1. 确保月报文件已存在（`日记/2026年/3月/2026年3月统计报表.md`）
2. 检查文件路径是否正确
3. 手动检查 Markdown 语法是否正确

## 注意事项

- 日记文件必须按照标准格式命名：`YYYY-MM-DD.md`
- 图表生成需要几秒钟时间（启动浏览器、截图）
- 生成的图片会覆盖同名文件
- 月报插入操作会修改原文件，建议提前备份
- 确保 Python 环境中已安装 playwright 和 chromium
